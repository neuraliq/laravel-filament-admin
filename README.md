# Laravel Filament Admin Panel Skill

An AI agent skill for building admin panels with Filament v3 — resources, forms, tables, widgets, and relation managers.

## Topics Covered

- CRUD resource generation and configuration
- Form schema (text inputs, selects, toggles, date pickers, password handling)
- Table builder (searchable, sortable, badges, filters, bulk actions)
- Dashboard widgets (stats overview with charts)
- Relation managers for hasMany/belongsToMany

## Installation

```bash
npx skills add neuraliq/laravel-filament-admin
# or
php artisan boost:add-skill neuraliq/laravel-filament-admin
```

## Compatibility

Claude Code, Cursor, Windsurf, GitHub Copilot

## Requirements

Laravel 11+, Filament v3
